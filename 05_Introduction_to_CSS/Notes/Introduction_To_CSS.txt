# Cascading Style sheet  

# Why do we need CSS ??
    * Styling 

# How to add CSS ?? 
    * Inline 
        * Same line as the tag 
        * Just a single element 
    * Internal 
        * Inside head -> <style> CSS added here </style>
        * Apply to one document ( not for multipage)
    * External
        * New css file is created and link tag in is added under head 
        * rel = 'stylesheet'
        * href = "./style.css"

# CSS SELECTORS 
    * Selectss html to apply rules 
    * Element Selector
        h1{
            color:blue;
        }
    * Class selector 
        .red-heading{
            color:red
        }
        # can be applied to more than 1 element 
    * id selector 
        #{
            color:blue
        }
        # cant be applied to more than 1 element 
    * Attribute selector 
        p[draggable]{
            color:red
        }
    * Universal Selector 
        *{
            color:red
        }
