### COMBINING CSS SELECTOR 

# GROUP -> apply to both the selector 

selector , selector {
    color:violet;
}

# CHILD -> applyto direct child 

selector > selector(applied to this) {
    colr : firebrick;
}

# DESCENDANT -> apply to descendant 

selector selector(applied to this ) {
    color:blue;
}

# CHAINING -. apply to where all selectors are true  

selectorselector{
    color:seagreen;
}
